# メモリンバー（Memorinber）

> **何もなかった、なんてことはない。**

メモリンバーは、高校生活の日常にある小さな出来事を「写真1枚＋一言」で残し、未来の自分が思い出を再発見するためのスマートフォン向けWebアプリです。

毎日日記を書くのではなく、友達との帰り道、放課後の教室、学校行事、何気ない会話など、「残しておきたい」と思った日に短時間で記録することを大切にしています。

## 体験の流れ

**残す → 集まる → 思い出す → 記憶をたどる**

- 写真と一言で、その日の出来事を残す
- 投稿が月ごとのアルバムに集まる
- 思い出クイズで忘れかけていた出来事を思い出す
- 人物やタグ、時期を手がかりに関連する記憶をたどる

## UIイメージ

![メモリンバーのUIプロトタイプ](./memorinber-ui-prototype.png)

温かいアイボリーを背景に、コーラルピンクと夕焼けオレンジをアクセントとして使用しています。青春、放課後、夕焼け、ノート、写真アルバムを感じられる雰囲気を保ちながら、装飾よりも写真と操作の分かりやすさを優先しています。

## 主な機能

### 思い出投稿

- 写真の選択とプレビュー
- 80文字までの一言入力
- 日付の指定
- 人物とタグの選択
- 投稿前の内容確認
- 写真・一言が未入力の場合のエラー表示

トップページは投稿に特化しており、アプリを開いた直後に「写真1枚＋一言」を迷わず残せる構成です。

### 月間アルバム

- 月ごとの写真一覧
- 月の切り替え
- 記録数と月を象徴するメッセージ
- 印刷画面を開くボタン
- BGMの再生・停止を模したUI

### 思い出クイズ

- ぼかした写真を使ったクイズ
- 選択肢からの回答
- 正解・不正解の表示
- ヒント表示
- 元の思い出詳細への移動

### 思い出詳細

- 写真、日付、一言の表示
- 人物とタグの表示
- 関連する思い出の表示
- 前後の思い出への移動

### その他

- サービスコンセプトの紹介
- デモデータの初期化
- プロトタイプであることの案内

## 画面とURL

| URL | 画面 | 内容 |
| --- | --- | --- |
| `/` | ホーム | 写真1枚＋一言の投稿に特化したメインページ |
| `/post` | 思い出投稿 | 独立した投稿フォーム |
| `/album` | 月間アルバム | 月ごとの思い出一覧、印刷、BGM UI |
| `/quiz` | 思い出クイズ | サンプルデータを使ったクイズ |
| `/memory/[id]` | 思い出詳細 | 個別の思い出と関連する記憶 |
| `/more` | その他 | サービス説明とデモ設定 |

## 技術構成

- [Next.js](https://nextjs.org/) 15（App Router）
- [React](https://react.dev/) 19
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/) 3
- [Lucide React](https://lucide.dev/)（アイコン）
- ESLint

スマートフォンファーストで設計しており、PCでは最大幅約430pxのコンテンツを中央に表示します。

## データについて

このリポジトリはUIプロトタイプです。初期表示にはモックデータと外部のサンプル写真を使用しています。

投稿した内容はReactの状態としてブラウザ内に一時保存され、同じセッション中はアルバムや詳細画面に反映されます。ページを再読み込みすると、追加した投稿は初期状態へ戻ります。

## 開発・実行手順

### 1. 必要な環境を用意する

以下をインストールしてください。

- Node.js 22.19.0
- npm（Node.jsと一緒にインストールされます）
- Git

このプロジェクトではNode.jsのバージョンを `22.19.0` に固定しています。nvmを使用している場合は、リポジトリ直下で次のコマンドを実行すると `.nvmrc` に指定されたバージョンへ切り替えられます。

```bash
nvm use
```

ターミナルまたはPowerShellを開き、バージョンを確認します。

```bash
node --version
npm --version
git --version
```

`node --version` の結果が `v22.19.0` になっていれば準備完了です。このプロジェクトではNode.js 22.19.0とnpm 10で動作確認しています。

### 2. リポジトリを取得する

まだリポジトリを取得していない場合は、次のコマンドを実行します。

```bash
git clone https://github.com/Rgh-33/Memorimber.git
cd Memorimber
```

すでに取得済みの場合は、ターミナルでこのリポジトリのフォルダへ移動してください。

### 3. 依存パッケージをインストールする

リポジトリ直下で次のコマンドを実行します。

```bash
npm install
```

`node_modules` フォルダが作成され、Next.js、React、Tailwind CSSなど、実行に必要なパッケージがインストールされます。初回は数分かかる場合があります。

### 4. 開発サーバーを起動する

```bash
npm run dev
```

起動に成功すると、ターミナルに次のようなURLが表示されます。

```text
Local: http://localhost:3000
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開くと、メモリンバーを閲覧できます。

開発サーバーを停止するときは、起動したターミナルで `Ctrl + C` を押してください。

### 5. ポート3000が使用中の場合

別のアプリがポート3000を使用している場合、Next.jsが自動的に3001などの別ポートを提案することがあります。ポートを明示する場合は次のように起動します。

```bash
npm run dev -- -p 3001
```

その場合は [http://localhost:3001](http://localhost:3001) を開いてください。

### 6. コードを検査する

ESLintでコードを検査します。

```bash
npm run lint
```

エラーが表示されなければ、Lintは成功です。

### 7. 本番用ビルドを確認する

最適化された本番用ファイルを生成し、型やルートを含めてビルドできることを確認します。

```bash
npm run build
```

ビルド成功後、本番用サーバーを起動できます。

```bash
npm run start
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。終了するときは `Ctrl + C` を押します。

本番用サーバーを別ポートで起動する場合は、次のように実行します。

```bash
npm run start -- -p 3001
```

### 8. 写真が表示されない場合

サンプル写真は外部URLから読み込むため、表示にはインターネット接続が必要です。ネットワークやフィルタリング設定によって読み込めない場合でも、写真選択エリアからローカル画像を選択して投稿プレビューを確認できます。

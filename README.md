# メモリンバー（Memorinber）

> **何もなかった、なんてことはない。**

メモリンバーは、高校生活の日常にある小さな出来事を「写真1枚＋一言」で残し、思い出の木を育てる体験を通して自分の思い出を振り返るためのスマートフォン向けWebアプリです。

毎日日記を書くのではなく、友達との帰り道、放課後の教室、学校行事、何気ない会話など、「残しておきたい」と思った日に短時間で記録することを大切にしています。

## 体験の流れ

**残す → 育つ → 思い出す → 言葉として残る**

- 写真と一言で、その日の出来事を残す
- 投稿が月ごとのアルバムに集まる
- 思い出クイズで忘れかけていた出来事を思い出す
- 人物やタグ、時期を手がかりに関連する記憶をたどる

### 思い出の木

ホームには、投稿した思い出が育っていく「思い出の木」を表示します。現在は体験を確認するための見た目のみですが、UIデータは次の3状態を独立して扱える構造にしています。

1. 写真を投稿すると、小さな実が `growing`（成長中）になり、`growth` で成長度を持つ
2. 一定まで育つと `quiz-ready`（クイズ可能）になり、実を押してクイズへ進める
3. クイズを終えると `harvested`（収穫済み）になり、自分で付けた単語が木の上へ漂う

木の画像、押せる実、収穫後の単語は別レイヤーです。今後データベースや成長条件を追加しても、木の画像を作り直さずに各思い出の状態を差し替えられます。

収穫済みの単語は、長押しして掴んだ後、ホーム画面内の好きな位置へ移動できます。文字の濃さは固定値ではなく、その時点の表示位置から木までの距離に応じて変化します。一定速度以上で縦横に振るか、くるくる回して12回分の動きを加えると関連する思い出を表示し、移動した配置は別画面へ移るまでの一時状態として扱います。現在はサンプルの関連付けですが、各単語が `relatedMemoryIds` を複数持てるため、将来は投稿内容やタグから抽出した関連思い出へ差し替えられます。

ヘッダーのメニューから設定画面を開けます。アクセントカラー、BGM音量、効果音音量は共通の設定状態として保存されています。`NEXT_PUBLIC_BGM_URL` に音源を設定すると、BGMは画面をまたいでループ再生され、設定のBGM音量へ常に追従します。音量を0にすると無音になります。

プロフィールでは、写真付きアイコン、ニックネーム、写真枚数を経験値にした最大20のレベル、過去の活動統計から表示する記録を扱います。レベル10以降は累計写真枚数とクイズ・収穫・共有などの追加条件を両方満たしたときに上がり、条件待ちの間に追加した写真も累計へ繰り越します。追加条件は直前のレベルへ到達した時点の活動値を基準に、その後の増加分だけで判定できる構造です。レベル要件・到達時点の基準値・記録定義はUIから分離しており、将来データベース上の実績値へ差し替えられます。

ページ遷移や画像読み込みなどの処理中は、各画面左上の芽アイコンと `Memorimber` が穏やかに点滅します。処理が完了すると通常表示へ戻り、異常時に表示が残り続けないよう安全停止時間も設けています。

## UIイメージ

![メモリンバーのUIプロトタイプ](./memorinber-ui-prototype.png)

白を基調に、淡い水色と濃紺をアクセントとして使用しています。記憶のやさしさを感じる余白のある画面構成で、装飾よりも写真と操作の分かりやすさを優先しています。

## 主な機能

### 思い出投稿

- 写真の選択とプレビュー
- 80文字までの一言入力
- 日付の指定
- 人物とタグの選択
- 投稿前の内容確認
- 写真・一言が未入力の場合のエラー表示

トップページから最近の思い出を振り返り、中央の追加ボタンから「写真1枚＋一言」を迷わず残せる構成です。

### 月間アルバム

- 月ごとの写真一覧
- 月の切り替え
- 記録数と月を象徴するメッセージ
- 印刷画面を開くボタン

### 思い出クイズ

- ぼかした写真を使ったクイズ
- 選択肢からの回答
- 正解・不正解の表示
- ヒント表示
- 元の思い出詳細への移動

### 思い出詳細

- 写真、日付、一言の表示
- 人物とタグの表示
- 関連する思い出の表示
- 前後の思い出への移動

### その他

- サービスコンセプトの紹介
- デモデータの初期化
- プロトタイプであることの案内

## データについて

このリポジトリはUIプロトタイプです。初期表示にはモックデータと外部のサンプル写真を使用しています。

投稿した内容はReactの状態としてブラウザ内に一時保存され、同じセッション中はアルバムや詳細画面に反映されます。ページを再読み込みすると、追加した投稿は初期状態へ戻ります。

## 認証について

ログイン・新規登録・ログアウト、Cookieセッションの更新、未ログイン時のページ保護、本人の `profiles` 読み取りまでを実装しています。`profiles` のINSERT・DELETEはフロントから行わず、登録時の行作成はDB側Triggerへ任せます。

Supabaseの接続情報が未設定の場合、ローカル開発では既存UIを確認できるようページ保護を一時的に通過させ、ログインフォームは無効表示になります。本番環境では設定不足のまま保護ページを公開しません。

メール確認の有無やメールテンプレートなど、Supabaseプロジェクト側の設定に依存する部分は実プロジェクト接続後に確認が必要です。

## 開発・実行手順

### 1. 必要な環境を用意する

以下をインストールしてください。

- Node.js 22.19.0
- npm（Node.jsと一緒にインストールされます）
- Git

このプロジェクトではNode.jsのバージョンを `22.19.0` に固定しています。nvmを使用している場合は、リポジトリ直下で次のコマンドを実行すると `.nvmrc` に指定されたバージョンへ切り替えられます。

```bash
nvm use
```

ターミナルまたはPowerShellを開き、バージョンを確認します。

```bash
node --version
npm --version
git --version
```

`node --version` の結果が `v22.19.0` になっていれば準備完了です。このプロジェクトではNode.js 22.19.0とnpm 10で動作確認しています。

### 2. リポジトリを取得する

まだリポジトリを取得していない場合は、次のコマンドを実行します。

```bash
git clone https://github.com/Rgh-33/Memorimber.git
cd Memorimber
```

すでに取得済みの場合は、ターミナルでこのリポジトリのフォルダへ移動してください。

### 3. 依存パッケージをインストールする

リポジトリ直下で次のコマンドを実行します。

```bash
npm install
```

`node_modules` フォルダが作成され、Next.js、React、Tailwind CSSなど、実行に必要なパッケージがインストールされます。初回は数分かかる場合があります。

Supabaseへ接続する場合は `.env.example` を参考に `.env.local` を作成し、プロジェクトの公開URLと公開キーを設定します。`service_role` やsecret keyは設定しないでください。

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_xxx
```

### 4. 開発サーバーを起動する

```bash
npm run dev
```

起動に成功すると、ターミナルに次のようなURLが表示されます。

```text
Local: http://localhost:3000
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開くと、メモリンバーを閲覧できます。

開発サーバーを停止するときは、起動したターミナルで `Ctrl + C` を押してください。

### 5. ポート3000が使用中の場合

別のアプリがポート3000を使用している場合、Next.jsが自動的に3001などの別ポートを提案することがあります。ポートを明示する場合は次のように起動します。

```bash
npm run dev -- -p 3001
```

その場合は [http://localhost:3001](http://localhost:3001) を開いてください。

### 6. コードを検査する

ESLintでコードを検査します。

```bash
npm run lint
```

エラーが表示されなければ、Lintは成功です。

### 7. 本番用ビルドを確認する

最適化された本番用ファイルを生成し、型やルートを含めてビルドできることを確認します。

```bash
npm run build
```

ビルド成功後、本番用サーバーを起動できます。

```bash
npm run start
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。終了するときは `Ctrl + C` を押します。

本番用サーバーを別ポートで起動する場合は、次のように実行します。

```bash
npm run start -- -p 3001
```

### 8. 写真が表示されない場合

サンプル写真は外部URLから読み込むため、表示にはインターネット接続が必要です。ネットワークやフィルタリング設定によって読み込めない場合でも、写真選択エリアからローカル画像を選択して投稿プレビューを確認できます。
